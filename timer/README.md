## Name
TyMoon

## Description
Un projet qui permet aux utilisateurs de configurer un chronomètre personnalisé, avec des boutons pour Démarrer, Pause, Reprendre, et Réinitialiser. Ce projet a été développé à la demande d'une entreprise afin d’offrir une expérience simple et intuitive pour gérer un timer sur le web.

## Installation
Pour exécuter ce projet sur votre machine locale, assurez-vous d'avoir les éléments suivants installés :

Un navigateur web moderne (Chrome, Firefox, etc.)
Aucun serveur ou backend requis, car il s'agit d'une application purement front-end.

## Usage
Choix de la durée du chronomètre.
Boutons interactifs pour Démarrer, Pause, Reprendre, et Réinitialiser le timer.
Interface simple et épurée.
Comportement réactif sur différents appareils.
